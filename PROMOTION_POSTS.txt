I just published `x402-cleanweb-agent` (v1.2.0 on PyPI) – an autonomous HTTP 402 micropayment gateway on Polygon that gives AI agents and LLMs the ability to scrape and clean web data without human accounts or $49/mo subscriptions.

### Why I built this:
Autonomous agents (CrewAI, LangChain, Claude) can't sign up with credit cards or KYC. By using HTTP 402 on Polygon Mainnet, agents can autonomously send $0.01 USDC and receive clean, token-optimized Markdown in < 0.4s (saving 70-85% LLM tokens).

### Key Highlights:
1. **Clean Web & Batch Clean**: Strip ads and HTML noise for single or up to 10 URLs in parallel.
2. **YouTube Transcript Extractor**: Timestamped transcripts in Markdown format (0.02 USDC).
3. **PDF Research Paper Extractor**: arXiv papers and earnings reports converted to clean Markdown.
4. **Self-Healing 402 Protocol**: If payment is short, returns structured JSON actionable instructions so the LLM automatically retries without human intervention.
5. **Claude / Cursor MCP Native**: Zero-install via `uvx x402-cleanweb-agent` or 1-click installer (`install_mcp.bat`).
